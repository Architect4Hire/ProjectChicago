# Vendored skills note

The JobBoard source repository documents additional third-party/vendor skills for fast-moving ecosystems. This Project Chicago review package does **not** copy third-party skill content.

If the target repository vendors official/community skills for Aspire, Playwright or other tools:

- keep upstream attribution/license information;
- pin/record the upstream version/commit;
- do not silently rewrite vendored content as if it were Project Chicago-authored;
- keep Project Chicago architecture rules in this repo's own `CLAUDE.md`, rules and skills;
- prefer official current documentation when vendored instructions conflict with current tooling.
